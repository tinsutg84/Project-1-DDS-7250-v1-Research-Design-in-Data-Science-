# Outputs

This folder contains the model outputs, evaluation results, and visualizations generated for the Stroke Prediction Using Machine Learning project.

## Project Outputs

The outputs include:

- Exploratory data analysis visualizations
- Stroke class distribution
- Stroke rates by age, glucose, BMI, and cardiovascular risk
- Random Forest feature importance
- Recursive Feature Elimination (RFE) performance
- Classification threshold evaluation
- ROC curve comparison
- Model performance and evaluation results

These outputs support the interpretation and comparison of the Random Forest feature importance and Recursive Feature Elimination approaches used in this study.
